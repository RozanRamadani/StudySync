# StudySync v1.0 - SRS Clarification & Final Constraints

This section overrides any ambiguous interpretation in the previous implementation plan.

These requirements have the highest priority.

---

# 1. Dashboard Responsibility

The Dashboard is the user's personal home page.

It is NOT:

- an analytics page
- a reporting page
- a Learning Intelligence page
- a Calculator

The Dashboard should feel like "Today's Workspace".

Keep the following components:

- Greeting
- Today's Coach (AdaptiveCoachCard)
- Quick Stats
- Last Recommendation
- Last Study Session
- Weekly Reflection (Compact Version)
- Burnout Warning (only when necessary)
- Quick Actions

Quick Actions should include

- Start New Session
- Open Learning Intelligence
- View History

The Dashboard must remain lightweight.

Do NOT place heavy analytical components here.

---

# 2. Study Tips Responsibility

Study Tips is a permanent educational library.

It is NOT part of Learning Intelligence.

It is NOT generated by AI.

It is NOT connected to Adaptive, Predictive, or Decision Engines.

Populate the page with curated educational content.

Organize content into categories.

Learning Techniques

- Pomodoro
- Deep Work
- Active Recall
- Spaced Repetition
- Feynman Technique
- Cornell Notes
- Memory Palace

Exam Preparation

- Revision Planning
- Time Management
- Focus Management
- Avoiding Burnout

Each article should contain

- Overview
- How it works
- Advantages
- Limitations
- Best Use Cases

This page must remain static educational content.

---

# 3. Learning Intelligence Structure

Learning Intelligence is an analytical center.

It is NOT a replacement for Calculator.

It is NOT a replacement for Fuzzy Logic.

It is NOT a replacement for Study Tips.

Organize Learning Intelligence using tabs.

Overview

Contains

- Learning Profile
- Habit Score
- Weekly Summary

Adaptive

Contains

- Pattern Recognition
- Burnout Detection
- Improvement Timeline

Predictive

Contains

- Tomorrow Forecast
- Weekly Forecast
- Trend Forecast
- Prediction Accuracy

Decision Analysis

Contains

- Decision History
- Decision Trends
- Decision Comparison

Simulation

Contains

- What-if Simulator

Each tab has a single responsibility.

Avoid duplicating components across multiple tabs.

---

# 4. Decision Support Responsibility

Decision Support consists of two different modules.

Runtime Decision Support

Location

Calculator

Purpose

Help users choose the best study plan immediately after calculateFuzzy().

Historical Decision Analysis

Location

Learning Intelligence

Purpose

Analyze previously selected study plans.

Do NOT move the interactive Decision Dashboard from Calculator.

Do NOT duplicate the Decision Dashboard inside Learning Intelligence.

---

Navigation order must remain consistent.

Desktop

Mobile

Tablet

Order

Dashboard

Calculator

Study Tips

Fuzzy Logic

Learning Intelligence

History

Settings

Do not remove any navigation item.

Do not merge educational pages.

---

# 6. UI Preservation Rules

Preserve the existing visual identity of StudySync.

Do not redesign pages unless explicitly requested.

Do not simplify pages by removing educational content.

Do not remove sections because they appear similar.

If two pages have different educational purposes,

keep both.

When uncertain,

preserve functionality rather than reducing page count.

Favor consistency over redesign.

always preserve the educational value.

StudySync is an educational platform first,

and an AI application second.
